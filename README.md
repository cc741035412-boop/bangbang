# 帮帮师记

把手机里的游戏素材，整理成教师能核对、保存和导出的观察记录。

这是一个面向幼儿园主班教师的工作项目。用户已说明项目源于前公司；个人职责、任职期间交付与本仓库后续迭代的边界待补充。当前代码形态为手机端 Web App / PWA。AI 提供客观白描草稿和指标建议，教师确认人物、核对事实、选择指标，并完成观察分析与支持策略。

**状态：源码展示版，手机端 Web App / PWA 仍处于试用迭代阶段。** 当前没有长期在线体验地址；本机临时测试链接不作为作品页长期入口。原生 iOS / Android 安装包不在本阶段范围内。

## 一次观察如何完成

1. 教师先用手机拍摄，回看时上传照片或视频、选择游戏区域。
2. 有目标时选择或补充观察目标，明确主观察幼儿和同时记录的其他幼儿，再生成白描；没有预设目标时可选择“先看看素材”。
3. 核对白描，通过衣着、位置和行为线索确认人物姓名；模型不把名单顺序当作画面身份。
4. 根据观察目标、人物信息、白描、年龄段和指标库生成候选指标，教师采纳、否决或自行补充。
5. 教师填写观察分析与支持策略，两项均为必填；可参考 AI 建议并改写。
6. 确认记录后预览、导出 Word / PDF，或按幼儿、区域、月份等检索。

## 已有能力

- 账号登录、园所与班级隔离、素材和记录归属校验。
- 照片与视频上传；单文件 200 MB、视频 3 分钟限制。
- 观察目标多选及自定义、主次幼儿分区选择、选择立即反馈与后台串行保存。
- 图片 / 视频抽帧生成白描、人物对应、候选指标及可改写的分析策略。
- 单条与月度导出；照片、视频代表帧嵌入 Word / PDF，支持 JPEG、PNG、HEIC、HEIF 输入。
- PWA 应用图标、主屏幕入口与基础离线外壳。上传、AI、保存、检索和导出仍需要网络。

## 本机运行：默认模拟体验

需要 Python 3.9+ 和 Node.js 22。以下命令在项目根目录开始执行。

```bash
python3 -m venv backend/.venv
backend/.venv/bin/python -m pip install -r backend/requirements.txt
backend/.venv/bin/python backend/run_demo.py
```

另开一个终端：

```bash
cd frontend
npm ci
npm run dev
```

打开 [本机登录页](http://localhost:5173/login)，选择注册新账号，填写虚构资料。先获取验证码，再使用页面提示的模拟验证码；注册后在设置中添加虚构幼儿。启动器不会预置朋友账号，也不会读取现有业务数据库。

`run_demo.py` 每次在系统临时目录创建新的数据库和素材目录，强制使用模拟短信与模拟 AI，不需要密钥、不产生真实模型调用。停止后数据不自动删除，下次启动使用另一个新目录。它仅监听本机，不用于直接公开服务。

要体验真实模型，需要另外配置服务端环境。配置项见 `backend/.env.example`；实际环境文件、API 密钥和用户素材不进入仓库。模拟模式只能验证交互与数据流程，不能证明模型识别或推理准确。

## 架构

| 部分 | 实现 |
|---|---|
| 手机界面 | React、TypeScript、Vite、Tailwind CSS |
| 数据请求与状态 | TanStack Query、OpenAPI 类型 |
| 后端与存储 | FastAPI、SQLModel、SQLite、本地私有素材目录 |
| 视频处理 | FFmpeg 按时长与画面变化抽帧，空白帧附近重采样 |
| AI | 豆包视觉 / 音频；DeepSeek 候选指标与分析策略；可切换模拟模式 |
| 导出 | python-docx、ReportLab |

## 目前的限制

- 抽帧由程序决定，不是模型自主观看完整视频。画面变化不等于重要教育行为，短暂动作可能漏掉。
- 分析策略调用目前只显式接收白描、区域和已采纳指标名称，尚未完整传入目标、主次对象、年龄段、层级及证据；策略也未依据教师修改后的分析再次生成。
- 白描提示中对帧间连续性的表述需要收紧，避免补写未观察到的过程。
- 视频时长的系统规则不能直接证明某位幼儿持续参与的时长，需要修正后再用于可信评估。
- 当前只做小范围试用，尚无可靠的节省时间、独立完成率或模型准确率结论。
- 当前演示不承载真实园所业务数据；不提供稳定公网、离线写入或原生商店版本。

## 素材与许可

当前源码版本不包含运行数据库、上传影像、真实导出、运行日志或密钥。旧故事板和旧构建包已不作为当前发行文件；历史记录保留，其中故事板来自 AI 生成素材、测试影像为程序生成图案。历史规划和示例中的耗时数字不作为当前产品成效证据。测试中的人物与手机号只用作程序夹具，不是联系方式。
