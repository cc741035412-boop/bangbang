# 文档目录约定

本目录只存放可持续维护的项目文档，不存放临时草稿。

文件使用小写英文和连字符命名，例如：

- `product-one-pager.md`
- `mvp-user-flow.md`
- `api-contract.md`
- `teacher-test-2026-08.md`

同一主题优先更新原文档，不使用 `最终版`、`最新版`、`v2-final` 一类文件名。需要版本记录时依赖 Git 历史或在文档内维护变更记录。

作品集文案维护在 `portfolio-case-study.md`；公开范围、素材来源及发布前核对维护在 `public-release-review.md`。历史产品定义保留日期，不把当时的计划当作当前已实现功能。个人联系方式、内部交接与机器配置不进入对外文档包。

历史产品定义、流程计划与迁移记录保留其日期和上下文，不代表当前功能、实测性能或上线成效。当前运行方式与能力以根目录 README 为准。内部交接资料和旧产物只保留在本机，不再纳入当前版本。
