# 白描标注手册

> 版本：v1 · 2026-08-30
> 配套文件：`docs/baimiao-scoring-rubric.md`（评分标准：定义与公式）
> 读者：标注员（有幼教经验的老师 / 产品经理 / 评测实习生）
> 标注一条白描预计耗时：10~15 分钟

## 1. 你的角色

你是**裁判**，不是作者。
你的任务是判断"AI 写的这段白描，跟视频里真实发生的对得上吗"，**不负责**替 AI 重写、不负责改错别字。
标准：宁可标"❓ 无法核实"，也不要凭感觉标"✅"或"❌"。

## 2. 准备工作（每条必做）

1. 看原视频 **至少 2 遍**（第 1 遍了解全貌，第 2 遍核对细节）。
2. 读该视频的**教师标准白描**——这是"发生了什么"的基准清单，写作比 AI 丰富是正常的。
3. 打开 AI 白描文本。
4. 打开标注表（模板见文末），先填：视频编号、视频时长、标准白描编号、AI 白描版本号（`prompt_version`）。

> 隐私提示：标准白描中的真实幼儿姓名已隐去，统一用「幼儿A/B/C…」指代。标注表、笔记、群聊中**一律不得出现真实姓名**。

## 3. 标注流程（六步）

1. **圈关键事件**：从标准白描里圈出 3~8 个关键事件，填进标注表"关键事件"栏。
2. **拆句**：把 AI 白描按《评分标准》第 2 节拆成事实句。
3. **逐句打勾**：✅ / ❌ / ❓ / ➖，每个 ❌ 必须在备注里写清视频证据。
4. **算覆盖**：AI 白描讲到每个关键事件了吗（✓ / △ / ✗）。
5. **定可用性**：L0~L3。
6. 填完表，签名，写一句"为什么这么判"。

## 4. 打勾细则（配合评分标准第 3 节）

### 4.1 ✅ 什么时候用
- 视频里能直接看到/听到，或标准白描证实了。
- 例：视频里确实有孩子在沙池 → "多名儿童在沙池活动" ✅。
- 例：标准白描写"金诗晨去关水"，视频里看到一名幼儿走向水龙头，AI 写"一名幼儿去关水" → ✅（AI 没写名字是正常的，见 6.4）。

### 4.2 ❌ 什么时候用
- **编造**：AI 写了画面里没有的东西。
  - 例：AI 写"穿红衣服的幼儿"，视频里没人穿红衣 → ❌。
- **张冠李戴**：把 A 的动作安到 B 身上。
  - 例：视频里是幼儿C 在铺膜布，AI 写"幼儿A 在铺膜布" → ❌。
- **时间点严重错位**：超出 ±10% 且影响理解。
  - 例：视频约 100 秒时已进入收尾，AI 写"约145秒仍在搭建立交桥" → ❌。
- **总结句掩盖事实**：AI 写"游戏仍在继续"，但视频里游戏已经结束/幼儿已离开 → ❌，不要因为它是"虚句"就放过。

### 4.3 ❓ 什么时候用
- 看不清、被遮挡、太远、过糊，实在无法核实。
- 例："背景里还有其他孩子在活动"（太远）→ ❓（能确认则 ✅）。
- ❓ 不计分，但多条 ❓ 说明白描写得太笼统，要在备注里指出。

### 4.4 ➖ 什么时候用
- 评价词："认真/专注/聪明/良好/较弱/有进步/棒/厉害"等 → ➖ + 记一次**客观性违规**。
- 推测："海桐想测试水流方向"（画面没明说意图）→ ➖ + 违规。
- ➖ 不进准确率分子分母，但每条白描违规 ≥2 次判整条不合格。

## 5. 常见坑（开工前必读）

| # | 坑 | 正确做法 |
|---|---|---|
| 5.1 | 标准白描比 AI 丰富，把 AI 缺的当"错" | 缺 = **覆盖率问题**，不是 ❌ |
| 5.2 | AI 没写对话 | 本阶段没接音频；记"能力边界缺口"，**不算 ❌ 也不算覆盖扣分**，单独列 |
| 5.3 | AI 用词不同但意思对 | ✅ |
| 5.4 | 拿标准白描当唯一答案 | **视频才是最终裁决** |
| 5.5 | 对时间戳较真到秒 | ±10% 内算对 |
| 5.6 | 只看文字不重看视频 | 每个 ❌ 都要有视频证据，写进备注 |
| 5.7 | 一句话一半对一半错 | 拆两句分别打勾 |

## 6. 两份完整标注示范（真实样例，已匿名）

### 样例 1：沙水区 · 无字幕（视频约 148 秒）

**教师标准白描（已隐去真实姓名）**：
> 幼儿A、幼儿B 等几个小朋友在后头挖沙道，幼儿C 在前头铺水道的塑料膜布，她说："用砖头压一下，待会这个布才不会溜走。"幼儿B 和幼儿D 在一旁寻找适合引水的管道，在最接近水源的轮胎处放置了支架，放了一个半圆 PVC 管，搭建好后他们就迫不及待开水，水流在浸润第一条膜布后难以继续往前流。幼儿D 走到 PVC 管处观察，说："到头了只能流到这里了。"幼儿E 则走到两块膜布的交界处说："这边咋不能流？"蹲在此处的幼儿C 说："这里（的膜布）太高了。"幼儿E 和幼儿C 扯一扯平膜布，试图让水流过来。幼儿D 发现了新问题："水都从轮胎处往外流了！"幼儿D 赶急去关水，幼儿E 走过去轮胎处，说："把沙子弄过去（堵住水流往外流），要堵住才行。"幼儿C 说到："我知道了，是高低的问题。"老师问："幼儿C 说到了高低的问题，你看开口这里哪边高哪边低？"孩子们思考了一会但没有正确的回应。

**AI 白描（wf-a-vision-v3）**：
> 约0秒，沙水区内多名儿童在沙池活动。前景一名扎双马尾的幼儿，穿白上衣、浅紫色短裙，脚蹬黄色雨靴，手中拿着一块红砖；沙池内一块布上已排列放置多块红砖，周边可见堆叠的旧轮胎、蓝色围边的水池，其余孩子有的持工具铲沙，有的在一排彩色水桶旁忙碌。
> 约74.3秒，场景切换至沙池另一区域，几名孩子围在架有白色长管的装置旁，一名穿粉上衣的女孩操作着黑色软管，周边散落着轮胎、塑料筐和金属容器，沙地上零星放着红砖。
> 约148.5秒，画面里一名扎双马尾、穿带图案上衣的幼儿蹲在沙中，手伸进沙里铺着的布里摆弄；背景有轮胎，还有孩子持瓶向沙中倒水，沙池里的搭建活动持续推进。

**拆句 + 打勾表**（❌ 都要回看视频核实后才填）：

| # | 事实句 | 判定 | 备注 |
|---|---|---|---|
| 1 | 约 0 秒 | ✅ | |
| 2 | 多名儿童在沙池活动 | ✅ | |
| 3 | 前景一名扎双马尾幼儿 | 视视频 | 标准白描未提外观，须看视频 |
| 4 | 穿白上衣、浅紫短裙、黄雨靴 | 视视频 | 同上 |
| 5 | 手中拿一块红砖 | 视视频 | |
| 6 | 一块布上排列多块红砖 | 视视频 | 与"铺膜布"呼应 |
| 7 | 周边有旧轮胎、蓝色围边水池 | 视视频 | |
| 8 | 约74.3秒场景切换 | ✅ | 弱事实 |
| 9 | 几名孩子围在白色长管装置旁 | 视视频 | 对应"引水管道"场景 |
| 10 | 一名穿粉上衣的女孩操作黑色软管 | 视视频 | |
| 11 | 约148.5秒一名幼儿蹲在沙中摆弄布 | 视视频 | |
| 12 | 有孩子持瓶向沙中倒水 | 视视频 | |
| 13 | "沙池里的搭建活动持续推进" | ⚠️ 总结句 | 查视频确认游戏是否已结束；未结束 ✅，结束 ❌ |

**关键事件覆盖**：

| 关键事件 | 覆盖 | 得分 |
|---|---|---|
| 挖沙道 | ✗ | 0 |
| 铺膜布、用砖压住 | △（只提到布和红砖） | 0.5 |
| 找管道、搭支架放 PVC 管 | △（74 秒装置场景，未讲因果） | 0.5 |
| 开水、水流受阻 | ✗ | 0 |
| 发现到头了/不流，判断"太高" | ✗ | 0 |
| 扯平膜布 | ✗ | 0 |
| 漏水、关水、用沙堵 | ✗ | 0 |
| "高低问题"总结 + 老师提问 | ✗（无音频，能力边界） | 0 |

覆盖率 = 1.0 ÷ 8 ≈ **13%**。

**可用性**：L2~L3。画面/材料/人数骨架在，但**事件主线（引水→受阻→堵漏→高低问题）全缺**，老师必须补写大半内容。判定 L3 更接近实际。

**一句话点评**：事实层面（画面细节）大概率合格，覆盖率是致命伤——这正说明**当前 3 帧 + 无音频**对"事件主线"的还原力不够，是后续要修的核心问题。

### 样例 2：沙水区 · 无字幕长视频（约 164 秒）

**教师标准白描（已隐去真实姓名）**：
> 幼儿A 选了红色 U 型管放在水池中间，不断进行调整，一头抵在水池壁上，一头搭在沙地上，幼儿B 将水从 U 型管往里倒，幼儿A 继续调整，说："这是倒水的滑滑梯。"幼儿C 拿起小鸭子，放在"滑梯"上端，将鸭子放下，很快鸭子就顺着 U 型管滑下去。其后幼儿A 拿掉红色 U 型管，摆放黄色短 U 型管，这次他没有将另一头抵在水池壁上。幼儿A、幼儿B 和幼儿C 拿起小鱼，尝试将它们从黄色 U 型管高的一头往下放，但是小鱼没有自己滑下去，而是他们用手推。然后幼儿A 拿起一个架子放在水池边，再将绿色 U 型管的一端架高。幼儿A、幼儿C 和幼儿D 轮流将自己手上的动物滑下去，动物也很顺利地滑下去。但是不一会，架子倒了，幼儿几番调整无果，便没有再继续游戏。

**AI 白描（wf-a-vision-v3）**：
> 约0秒时，沙水区的沙地上，穿条纹上衣黄雨靴的孩子左侧露半身，戴黑帽穿白上衣黄雨靴的孩子蹲着摆弄红色长管，旁边穿浅蓝上衣的孩子蹲在沙中摆弄小物件，周围分布塑料筐、玩具等沙水游戏材料，孩子们在沙区各自玩耍。
> 约82秒时，沙区孩子数量增多，扎马尾戴遮阳帽的孩子站立着，原本拿红管的白上衣孩子起身跑动，穿浅蓝色上衣的孩子四散，戴宽边帽的孩子蹲在沙中，玩具与游戏材料位置有明显变动。
> 约164秒时，孩子们聚集在一起，红色长管放在沙地上，几个穿浅蓝色上衣的孩子围在周边，有的蹲身触碰红管，白上衣孩子蹲在沙中，左侧有黄色玩具壶，沙区游戏仍在继续。

**拆句 + 打勾表**（节选关键几行）：

| # | 事实句 | 判定 | 备注 |
|---|---|---|---|
| 1 | 约 0 秒有孩子在沙地 | ✅ | |
| 2 | 戴黑帽、穿白上衣黄雨靴的孩子蹲着摆弄红色长管 | 视视频 | 对应幼儿A 调整红管 |
| 3 | 约82秒原本拿红管的白上衣孩子起身跑动 | 视视频 | |
| 4 | 约164秒红色长管放在沙地上 | 视视频 | 对应"换管/结束"阶段 |
| 5 | "沙区游戏仍在继续" | ⚠️ 重点核对 | 标准白描显示**架子倒了、游戏已结束**——若视频确实结束，此句 = ❌（总结句掩盖事实），而不是放过 |

**关键事件覆盖**：

| 关键事件 | 覆盖 | 得分 |
|---|---|---|
| 红 U 型管架水池中间（一头抵池壁） | △（提到红管，未讲架法） | 0.5 |
| 倒水，命名"倒水的滑滑梯" | ✗ | 0 |
| 放小鸭子滑下去 | ✗ | 0 |
| 换黄色短 U 型管 | ✗ | 0 |
| 放小鱼没滑、用手推 | ✗ | 0 |
| 架子架高绿色 U 型管 | ✗ | 0 |
| 轮流滑动物成功 | ✗ | 0 |
| 架子倒了、调整无果、停止游戏 | ✗（且"仍在继续"疑似与事实相反） | 0 |

覆盖率 = 0.5 ÷ 8 ≈ **6%**。

**可用性**：L3（重写）。AI 只描述"孩子在摆弄管子"，完全没讲"滑梯"这条游戏主线。

**一句话点评**：同样是"画面事实基本对、事件主线几乎全漏"。**加帧数（3→5 或按事件采样）只可能部分缓解"漏动作"，对话缺失必须靠接 ASR 才能补**。

## 8. 交付物

- 标注表（Excel / 多维表格），每条一行，含备注。
- 每次评测一个批次（建议 10~20 条），汇总出三个准确率 + 可用率。
- 批次报告里列出：本批最差的 3 条 + 失败归因（抽帧 / 提示词 / 无音频 / 模型），供改进闭环使用。
