# 白描评分标准（拆句打勾版）

> 版本：v1 · 2026-08-30
> 配套文件：`docs/baimiao-annotation-manual.md`（标注员操作手册）
> 适用对象：AI 生成的客观白描。参照物 = **原视频**（最终裁决）+ **教师标准白描**（重要事件清单）。

## 0. 一句话

把一段白描**拆成一句句可对着视频验证的事实**，逐句打 ✅/❌/❓，再补两个维度（关键事件覆盖、老师改动成本），得到三个数字：**事实准确率、覆盖率、可用性**。

## 1. 三个准确率的定义与公式

| 指标 | 衡量什么 | 公式 | 目标 |
|---|---|---|---|
| **事实准确率** | 编造了多少（每句是否属实） | ✅ ÷ (✅ + ❌) | ≥ 95% |
| **覆盖率** | 漏了多少（关键事件讲到几个） | 覆盖关键事件数 ÷ 标准关键事件总数 | ≥ 70% |
| **可用性** | 老师改多少才能用 | (L0 原样可用 + L1 微改) ÷ 样本总数 | ≥ 80% |

补充说明：
- ❓（无法核实）**不计入**准确率分子分母，但单独统计"不确定率"——❓越多说明白描越含糊。
- 出现评价词（认真/专注/有进步/棒等）记一次**客观性违规**（见第 6 节），违规超过阈值（如 2 次/条）则整条判不合格。

## 2. 怎么拆句

### 2.1 事实句的定义
一个"事实句" = 一个**可以对着视频验证对错**的断言。
判据：问自己一句"这段画面（或声音）能不能证明这句话？"
- 能 → 事实句；
- 不能 → 不是事实句（过渡语、总结虚句、评价、推测）。

### 2.2 拆句操作规则
1. 按**动作/状态的最小单元**切：一句话里有 2 个动作就拆成 2 句。
2. 引号里的原话算 1 句（事实内容是"某人说了这句话"）。
3. "约X秒"时间戳：单独算 1 个**低权重**事实句（误差 ±10% 内算对）。
4. "场景切换至……"算 1 个弱事实句。
5. **不算事实句**：
   - 连接词/过渡语（"其后""接着"）；
   - 总结性虚句（"游戏仍在继续""活动持续推进"）——不参与准确率，但它可能掩盖"游戏实际已结束"这类事实错误，见 7.5；
   - 评价词与推测（出现即另记客观性违规）。

### 2.3 拆句示范（沙水区 AI 白描节选）
原文：`约0秒，沙水区内多名儿童在沙池活动。前景一名扎双马尾的幼儿，穿白上衣、浅紫色短裙，脚蹬黄色雨靴，手中拿着一块红砖；沙池内一块布上已排列放置多块红砖，周边可见堆叠的旧轮胎、蓝色围边的水池……`

| # | 事实句 | 打勾（以视频为准） |
|---|---|---|
| 1 | 约 0 秒 | ✅ |
| 2 | 多名儿童在沙池活动 | ✅ |
| 3 | 前景有一名扎双马尾的幼儿 | 待核实 |
| 4 | 该幼儿穿白上衣、浅紫色短裙、黄色雨靴 | 待核实 |
| 5 | 该幼儿手中拿着一块红砖 | 待核实 |
| 6 | 沙池内一块布上排列着多块红砖 | 待核实 |
| 7 | 周边有堆叠的旧轮胎、蓝色围边水池 | 待核实 |

（"待核实"= 标注员必须回看视频，能确认写 ✅，看不清写 ❓，对不上写 ❌。）

## 3. 打勾标准

| 标记 | 含义 | 什么时候用 |
|---|---|---|
| ✅ | 属实 | 视频或标准白描能证实 |
| ❌ | 不符 | ①画面里没有的事（编造）；②张冠李戴（把 A 的动作安到 B 身上）；③时间点严重错位（超出 ±10% 且影响理解） |
| ❓ | 无法核实 | 画面看不清/被遮挡/太远/过糊 |
| ➖ | 不适用 | 评价词、推测意图（出现即另记违规，不进准确率） |

**判定铁律**（标注员必须遵守）：
1. 以**原视频**为最终裁决，标准白描不是"唯一答案"。
2. AI 写了标准白描里没有的细节 → 不算错，需对照视频核实（很可能 ✅）。
3. 标准白描有、AI 没写 → 不算 ❌，记入**覆盖率缺口**。
4. 意思对、用词不同（"用砖头压一下" vs "把砖头放上去"）→ 算 ✅。

## 4. 覆盖率怎么标

1. 标注员**先看视频 + 标准白描**，从标准白描圈出 **3~8 个关键事件**（有因果推进的完整动作单元）。
2. 再读 AI 白描，逐个关键事件打：
   - ✓ = 讲到了；
   - △ = 只提到一半/相关但没讲清楚（记 0.5）；
   - ✗ = 完全没提。
3. 覆盖率 = ∑得分 ÷ 关键事件总数。

**示范**（沙水区视频，关键事件来自教师标准白描）：

| 关键事件 | AI 白描覆盖 | 得分 |
|---|---|---|
| 后头挖沙道 | 没提 | ✗ 0 |
| 铺膜布、用砖头压住防溜走 | 提到"布"和"红砖"，但没讲压布目的 | △ 0.5 |
| 找管道、在轮胎处搭支架放 PVC 管 | 74 秒处提到"白色长管装置、软管"，未讲搭建因果 | △ 0.5 |
| 开水后水流受阻 | 没提 | ✗ 0 |
| 发现"到头了/交界处不流"，判断膜布太高 | 没提 | ✗ 0 |
| 扯平膜布试图让水流 | 没提 | ✗ 0 |
| 发现水从轮胎处外流，关水、用沙堵住 | 没提 | ✗ 0 |
| 幼儿总结"高低问题"、老师提问 | 没提（且无音频，属能力边界） | ✗ 0 |

覆盖率 = 1.0 ÷ 8 ≈ **13%**。

> ⚠️ **能力边界缺口**：本阶段 AI 未接语音转写（ASR），对话与教师提问**天然缺失**。这类缺失单独标注为"能力边界缺口"，**不与**"画面里能看到却没写"的遗漏混在一起统计——后者才是真要修的。

## 5. 可用性四级

| 等级 | 判定 | 说明 |
|---|---|---|
| L0 原样可用 | 一个字不用改 | 理想态，很少见 |
| L1 微改 | 改 ≤20 字（补幼儿名/删半句） | 老师顺手能改 |
| L2 大改 | 需要补写关键事件或重写部分段落 | 骨架在，故事缺 |
| L3 重写 | 不能用，从头写 | 事实错/事件全漏 |

可用率 = (L0 + L1) ÷ 样本总数。

## 6. 综合分（可选，用于版本对比）

**总分 = 事实准确率 × 0.5 + 覆盖率 × 0.3 + 可用率 × 0.2**，再减去客观性违规（每处 −1）。

| 分数 | 结论 |
|---|---|
| ≥ 85 | 可以上线试运行 |
| 70 ~ 85 | 可用，但需持续监测 |
| < 70 | 需要修：抽帧策略 / 提示词 / 接入音频转写 |

## 7. 特殊情况裁定

| 情况 | 裁定 |
|---|---|
| 时间戳差几秒 | ±10% 内 ✅；超出且影响理解 → ❌ |
| "幼儿A"指代混乱 | 指代不清导致事实描述张冠李戴 → ❌ |
| 环境描述（户外/带顶棚/遮阳伞） | 属弱事实句，逐句核实；单处错不重罚，错多处按 ❌ 计 |
| 台词与标准白描用词不同 | 原话以视频为准；AI 没写对话归覆盖率/能力边界 |
| 总结句掩盖事实错误（如游戏实际结束却写"仍在继续"） | 按事实错误 ❌ 处理，不只当"虚句"放过 |
| AI 写了标准白描没有的细节 | 对照视频核实，属实 ✅，不因"标准白描没写"而罚 |
| 一句话既对又错（一半对一半错） | 拆成两句分别打勾，不整句判错 |
